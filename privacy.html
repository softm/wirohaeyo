개인정보 처리 안내

시행일: 2026년 10월 26일 · 위로해요 0.2 · 개발자: softm

위로해요는 내 삶의 기록을 안전하게 보관하고, 사용자가 선택한 기록을 근거로 조용한 위로를 전하는 개인용 앱입니다. 계정 가입이나 원격 AI 서버 없이 동작하도록 설계했습니다.

1. 기록 저장

일기, 감정 체크, 직접 입력한 글, 선택하여 가져온 파일, 사진, 키워드 분석 결과를 기기 내 IndexedDB에 개별 AES-GCM 암호문으로 보관합니다. 사용자가 입력한 암호에서 PBKDF2-SHA-256으로 키를 파생하며, 암호나 복호화 키를 당사 서버에 저장하지 않습니다.

2. 접근 범위와 자동 수집

사용자가 고른 파일이나 Android 공유 기능으로 보낸 글·사진만 가져옵니다. 앱은 문자, 연락처, 통화 기록, 위치나 SNS 계정에 자동으로 접근하지 않습니다. 5분 이상 비활성 상태로 전환되면 보관함을 잠급니다. 개인정보 분석은 기기에서 수행되며, 가져온 자료는 기본적으로 분석에 포함하지 않습니다.

3. 외부 전송과 광고

개인 보관함의 원문·분석 결과를 앱 운영 서버로 자동 업로드하지 않습니다. 광고 SDK·사용자 행태 분석 SDK도 탑재하지 않습니다. Android 앱은 INTERNET 권한을 요청하지 않습니다. 단, 공개 웹앱에 접속하면 GitHub Pages 등 정적 호스팅 제공자가 접속 요청 정보(IP 주소 등)를 자신의 정책에 따라 처리할 수 있습니다.

4. 암호화 백업

‘암호화 백업’을 누르면 사용자가 지정한 파일 위치(원하는 경우 개인 클라우드 폴더)에 암호화된 JSON 파일을 저장할 수 있습니다. 공통 계정 연결 후 사용자가 백업을 선택하면 Firebase Authentication으로 로그인하고, Google Cloud Firestore의 사용자별·위로해요별 보관소에 암호화 백업을 전송합니다. 자동 백업 체크를 켠 경우 해당 창이 실행되는 동안 변경 후 백업하며, 로그아웃하거나 창을 닫으면 중지합니다. 암호·복호화 키·평문 기록은 전송하지 않습니다. 클라우드에는 계정 식별자, 사이트 ID, 암호문, 백업 크기·체크섬·저장 시각이 보관됩니다. 원격 백업은 백업 목록에서 삭제할 수 있으며 기기 기록 삭제와는 별개입니다. 로그인만으로 SNS 자료를 읽지 않습니다.

5. 열람·수정·삭제와 보유 기간

사용자는 기록을 확인하고 삭제하거나, 가져온 파일별 분석 포함 여부를 변경할 수 있습니다. ‘전부 삭제하기’는 해당 기기의 보관함을 지웁니다. 별도로 내보낸 백업 파일이나 타 기기에 복원한 파일은 자동으로 지워지지 않습니다. 앱 삭제 또는 브라우저 사이트 데이터 삭제 시 기기의 기록이 함께 삭제될 수 있습니다.

6. 암호 분실 및 보안 범위

암호 분실 시 운영자가 복구할 수 없습니다. 사용 중 기기·화면 노출, 악성코드, 탈옥·루팅, 유출된 백업 암호 등은 기기 내 암호화만으로 완전히 막을 수 없습니다. 다른 사람의 개인정보가 포함된 기록은 당사자의 권리와 관련 법령을 고려해 저장해 주세요.

7. 기능 변경

향후 SNS 공식 계정 연결, 원격 백업, 알림 등의 기능을 추가할 때는 별도의 명시적 동의와 설정·철회 수단을 제공합니다. 공통 계정 연결과 백업은 사용자가 선택할 때만 활성화됩니다. 현재 앱에 없는 기능이 자동 활성화되지는 않습니다.
