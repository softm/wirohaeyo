# 공통 계정 아이콘 메뉴

상단 계정 영역은 `/shared/platform/v1/site-account.mjs?v=20261030-menu-1`의 `mountSiteAccount`를 사용한다. 기존 로그인·회원가입·보관소 진입 버튼은 공통 메뉴가 준비된 뒤 숨긴다. 로그인 이후 Firebase 사용자 프로필의 실제 이미지를 표시한다.

- 인증 세션 복원은 로컬 보관함 열기, 기록 읽기, 백업 업로드를 실행하지 않는다.
- 기존 WiroCloudBridge와 암호화 백업 형식은 유지한다.
- 내 보관소 메뉴는 기기 보관함을 연 뒤 설정의 백업 관리로 이동한다.
- 자동 백업은 사용자가 선택해야 시작하며 계정 변경·로그아웃 때 해제한다.
- CSP는 HTTPS Google/Kakao/Naver 이미지 CDN만 추가 허용했다. 스크립트/스타일의 unsafe-inline은 추가하지 않았다.
- 캐시는 wirohaeyo 접두사의 이전 버전만 정리하며 다른 한눈 앱의 캐시를 삭제하지 않는다.
- 오프라인 Android 패키지는 기존 웹 인증 제한을 유지한다. 이번 작업은 새 네이티브 인증 구현이나 앱 스토어 릴리스가 아니다.

합성 브라우저 검증: 320/390/1280px, 엄격한 CSP, 세션 복원, 프로필 이미지, 기존 버튼 숨김, 로그아웃 이미지 제거, 복원 시 기록 읽기/업로드 0회 통과. 실제 SNS 로그인·운영 배포 검증은 별도다.
