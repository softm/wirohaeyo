# 위로해요 — 기획·개발 명세 v0.2

## 목적과 문장

- 목적: 나에게 흩어져 있는 기록을 안전하게 모으고, 내가 지나온 시간에 대한 증거를 통해 작고 조용한 위로를 건네는 개인 동반자.
- 사용자 가치: 기록할 때, 힘들 때, 생각날 때, 오래된 기억을 꺼내보고 싶을 때 스스로를 인정할 수 있다.
- 어조: 과장된 아부·경쟁·훈계·행복 강요·의료 진단 금지. 사용자가 쓴 문장과 실제 행위를 존중하며 인용 시 출처를 보여준다.
- 지향점: '나를 추앙하다'는 타인보다 우월하다고 주장하는 것이 아니라, 나의 고단한 수고와 존재를 가볍게 취급하지 않는다는 의미.

## 연속 분석 파이프라인(현재 및 설계)

1. **캡처:** 사용자가 입력하거나 파일·공유 텍스트를 명시적으로 선택.
2. **범위 설정:** 데이터 출처와 분석 포함 동의를 저장(가져온 파일 기본 비활성).
3. **로컬 암호화:** AES-GCM 개별 레코드, 키는 암호에서 파생, 원문 서버 전송 없음.
4. **로컬 분석:** 내 기록 수·해낸 일·감정 체크·7일 차트·실제 기록 기반 위로·분석 동의한 가져오기 기록의 로컬 키워드 추출.
5. **변화 기록:** 앱 열기/기록 추가 시 날짜별 통계 스냅샷을 암호화해 저장.
6. **위로 렌더링:** 특정 성취·감사 기록이 있으면 일부를 인용하고 근거를 날짜·자료 종류와 함께 표시.
7. **백업:** 암호화 데이터만 사용자의 파일로 내보내기. 자동 외부 업로드 없음.

## 후속 버전 우선순위

P1: 완료: 가져오기 기록별 분석 포함 토글, SHA-256 중복 가져오기 방지, 출처 메타데이터·가져오기 용량 제한, 5분 백그라운드 자동 잠금. 남음: 출처별 검색·용량 관리 화면·백업 복원 E2E 테스트·Android AAB/기기 검증·개인정보보호 정책.  
P2: 명시적 동의 기반 로컬 이벤트 인덱서(지속 분석), 온디바이스 텍스트 요약 모델 선택, 일별/주별 작은 위로 알림(발송 빈도 사용자가 설정), 휴대폰 사진 메타데이터 기반 연대기.  
P3: 사용자가 직접 선택한 클라우드에 **종단간 암호화된 파일만** 자동 백업, 다중 기기 키 관리, SNS 공식 연동(OAuth 권한 최소화·철회·원본 삭제).

## 안전 품질 기준

- 감정 점수는 비교·진단용이 아닌 개인 기록일 뿐이다.
- 위로는 사용자가 주지 않은 성격·능력·인생 사건을 지어내지 않는다.
- 부정적 감정이 들어왔다고 자동 공개·SNS 업로드·지인 통보하지 않는다.
- 도움을 강요하지 않고, 긴급한 위기 메시지라면 응급 서비스나 믿을 수 있는 주변 사람 도움을 부드럽게 권한다(향후 설계).
- 앱 유지·삭제·가져오기·내보내기·분석 포함의 통제권은 사용자에게 있다.
- 백업은 개인 데이터이므로 GitHub, Pages 빌드 산출물, CI 아티팩트에 절대 포함하지 않는다.
